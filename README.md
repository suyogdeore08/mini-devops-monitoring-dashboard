# ⚡ Mini DevOps — System Monitoring Dashboard

A dark-themed system monitoring dashboard built with **React, TypeScript, and Vite** to visualize system health and resource utilization through a clean, technical interface.

This project is being developed as a **Web Technologies mini-project**, with the goal of learning frontend development, backend integration, REST APIs, and system monitoring through hands-on implementation.

## 🎯 Project Objectives

- Build a responsive dashboard for monitoring system performance.
- Visualize CPU, memory, disk, and network utilization.
- Learn component-based development using React and TypeScript.
- Integrate a Node.js and Express backend for collecting system metrics.
- Explore real-time updates, alerts, and historical performance tracking.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/mini-devops-monitoring-dashboard.git
```

**2. Navigate to the project directory**

```bash
cd mini-devops-monitoring-dashboard
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🗺️ Development Roadmap

6. **Visualizations** — add charts and periodic metric updates.
7. **Service health and alerts** — display service status, warnings, and logs.
8. **Historical data** — persist selected metrics using MongoDB.
9. **Testing and deployment** — validate functionality and publish the application.
